# English

## FastAPI Studies

### Overview

This project was created to deepen my study of the [FastAPI](https://fastapi.tiangolo.com/) documentation.
FastAPI is a Python framework focused on building APIs.

### Minimum Installation Requirements

* Python (version 3.6 or higher)
* pip install fastapi
* pip install "uvicorn[standard]"

### Running

* To run any of the examples, copy the code into a file named main.py
* By default, the server runs on localhost, port 8000

  Run in the terminal:
```bash
uvicorn main:app
```

### Interactive Documentation

* While the server is running, you can open the automatic interactive API documentation at http://127.0.0.1:8000/docs. It is generated automatically by FastAPI and lets you test and explore the API interactively.

### API Testing

* [Postman](https://www.postman.com/) was used to test the API

### Recommendations

* This project is meant for studying and experimenting with FastAPI. Explore the official FastAPI documentation to get a deeper understanding of its features and capabilities.
